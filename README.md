# Aternos Watcher

تطبيق Android بواجهة عربية لمراقبة ثلاثة عناوين Minecraft وإرسال إشعار عند اكتشاف انتقال السيرفر من Offline إلى Online.

## الميزات
- واجهة عربية داكنة تعرض حالة كل سيرفر.
- فحص يدوي من زر «فحص الآن»، مع زر «اختبار الإشعار».
- فحص تلقائي عبر Android WorkManager كل 15 دقيقة كحد أدنى تقريباً (قد يؤخر النظام التنفيذ).
- إشعار بصوت واهتزاز عند اكتشاف انتقال معروف من Offline إلى Online.
- عرض عدد اللاعبين وإصدار Minecraft عند توفرهما.
- لا يحتاج إلى تسجيل دخول Aternos أو مشاركة كلمة مرور.

## آلية الفحص وحدودها
- يتصل التطبيق بعنوان السيرفر ومنفذه وينفذ Minecraft Server List Ping مباشرة؛ لا يدخل لاعباً ولا ينشئ بوتاً.
- هذا فحص بروتوكولي وليس API رسمية من Aternos، وقد لا يطابق دائماً حالة لوحة Aternos.
- إذا تعذر الاتصال أو انتهت المهلة أو فشل تحليل الرد، يعرض التطبيق UNKNOWN بدلاً من اعتبار السيرفر Offline.
- أول فحص يحفظ الحالة الأساسية فقط ولا يرسل إشعاراً؛ الإشعار يصدر عند انتقال لاحق من OFFLINE إلى ONLINE.
- Android WorkManager يضمن جدولة دورية بفاصل لا يقل عن 15 دقيقة، لكنه لا يضمن إشعاراً فورياً بالدقيقة بسبب قيود البطارية والشبكة.
- لا يستخدم التطبيق حساب Aternos أو بيانات تسجيل الدخول، ولا يحاول إبقاء السيرفر قيد التشغيل.

## بناء APK
كل Push إلى فرع main يشغّل GitHub Actions. افتح تبويب Actions، ثم افتح آخر عملية ناجحة، ونزّل Artifact باسم AternosWatcher-APK. فك ضغط ZIP لتحصل على app-debug.apk.

## ملاحظة
ملف APK الناتج Debug وغير موقّع للنشر العام؛ مناسب للتثبيت والتجربة الشخصية.
