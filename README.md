# Aternos Watcher

تطبيق Android بواجهة عربية لمراقبة ثلاثة عناوين Minecraft وإرسال إشعار عند انتقال أي سيرفر من Offline إلى Online.

## الميزات
- واجهة عربية داكنة تعرض حالة كل سيرفر.
- فحص يدوي من زر «فحص الآن».
- فحص تلقائي عبر Android WorkManager كل 15 دقيقة تقريباً (قد يؤخر النظام التنفيذ).
- إشعار مرتفع الأهمية مع صوت واهتزاز عند اكتشاف انتقال Offline إلى Online.
- لا يحتاج إلى تسجيل دخول Aternos أو مشاركة كلمة مرور.

## بناء APK
كل Push إلى فرع main يشغّل GitHub Actions. افتح تبويب Actions، ثم افتح آخر عملية ناجحة، ونزّل Artifact باسم AternosWatcher-APK. فك ضغط ZIP لتحصل على app-debug.apk.

## ملاحظات مهمة
- يعتمد الفحص على خدمة عامة خارجية mcsrvstat.us وليس على API رسمية من Aternos؛ لذلك قد تختلف النتيجة أو تتأخر.
- أول فحص يحفظ الحالة الأساسية فقط ولا يرسل إشعاراً.
- Android WorkManager يضمن جدولة دورية بفاصل لا يقل عن 15 دقيقة، لكنه لا يضمن إشعاراً فورياً بالدقيقة بسبب قيود البطارية والشبكة.
- اسم APK الناتج Debug وغير موقّع للنشر العام؛ مناسب للتثبيت والتجربة الشخصية.
